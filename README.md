# 🌿 Etsy-Style Telegram Bot

A Telegram bot for managing secure deals between users — inspired by Etsy's focus on trust, user experience, and clean interfaces.

## ✨ Features

- 🤝 Buyer/Seller role system
- 🌍 Multi-language support (English, Russian, Chinese)
- 🔐 Unique deal ID generation
- 💬 FSM-driven conversation flow (Aiogram 3)
- 📦 Persistent storage via JSON
- 🛡️ Safe cancel/confirm mechanisms
- 🧑‍🤝‍🧑 Group chat support

## 🚀 Quick Start

```bash
git clone https://github.com/your-username/etsy-deal-bot.git
cd etsy-deal-bot
